Jarvis

Règles de confidentialité

Dernière mise à jour : 6 novembre 2026.

Qui est concerné

Jarvis est une application privée, utilisée uniquement par son propriétaire avec son propre compte Google. Elle n'est pas proposée au public.

Données consultées

L'application accède uniquement aux fichiers qu'elle a elle-même créés dans son dossier de sauvegarde sur le Google Drive du propriétaire. Elle ne lit aucun autre fichier de ce compte.

Utilisation

Ces fichiers sont des sauvegardes de l'installation Home Assistant du propriétaire. Ils sont chiffrés avant leur envoi et servent uniquement à restaurer cette installation.

Partage

Aucune donnée n'est vendue ni partagée avec un tiers. Les sauvegardes sont stockées chez Google, dans le compte du propriétaire. Cette page ne contient ni publicité, ni cookie, ni outil de mesure d'audience.

Conservation et suppression

Les sauvegardes restent sur le Google Drive du propriétaire, qui peut les supprimer à tout moment. L'accès de l'application peut être retiré depuis la page Applications tierces du compte Google.

Contact

Pour toute question, ouvrez un ticket sur le dépôt GitHub de cette page.

In English

Jarvis is a private application used only by its owner, with their own Google account. It is not offered to the public.

It only accesses the files it created itself in its backup folder on the owner's Google Drive, and reads no other file in that account. These files are encrypted before upload and are used only to restore the owner's Home Assistant installation.

No data is sold or shared with third parties. Backups are stored by Google in the owner's account, and the owner can delete them at any time. Access can be revoked from the third-party apps page of the Google account.

For questions, open an issue on the GitHub repository of this page.
